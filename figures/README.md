# 재현 결과 그림

회기동(건물 783개)과 동대문구 전체(18,104개)에서 GEO-SOM의 지리적 승자 쏠림, 수정본, 군집 수 탐색(Gap Statistic)을 확인한 결과 그림입니다. 서울 전체가 아닙니다. 해석은 상위 [README](../README.md)의 "재현 결과"를 보세요.

- 수치는 회기동(01~06)은 제가 Colab에서 직접 실행한 결과이고, 동대문구(07~10)는 AI 도구가 제 Colab 화면에서 대신 실행한 결과입니다. 그림은 한글 폰트를 적용하려고 저장해 둔 결과로 AI 도구가 다시 그렸습니다(재학습 없음).
- 막대그래프는 건물마다 고른 지리적 승자가 몇 번 노드(0~399)였는지 센 것이고, 지도는 최종 군집입니다. 지도의 색은 20색이 반복되므로 같은 색이 같은 군집이라는 뜻이 아닙니다.
- 제목의 "응집도 lift"는 가까운 이웃 5개가 같은 군집인 비율을, 라벨을 섞은 기준선으로 나눈 값입니다. 군집이 잘게 쪼개질수록 높아져서 군집 품질의 지표가 아닙니다.
